# Additional background music

Downloaded on 2026-10-04 from the original OpenGameArt pages below. Each page offers CC0 1.0. This project uses the CC0 option. Files are served locally and fetched on demand after audio is unlocked by a user gesture. To keep mobile downloads and decoded memory small, Chills and Quirky Jazz use 90-second excerpts and Synthwave House Loop keeps its 50.5-second duration. All three are transcoded to stereo AAC at 32 kHz / 96 kbit/s with one-second edge fades and conservative peak adjustment. Original downloads are preserved outside the repository in the local temporary directory. These adaptations are permitted under CC0.
